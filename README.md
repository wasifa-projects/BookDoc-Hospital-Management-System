# BookDoc — A Hospital Management System

## About the Project

BookDoc is a PHP-based Hospital Management System developed as a group project for **CSE347 – Computer Information and Systems Analysis**.

The project focuses on applying software development and systems analysis concepts to a hospital management scenario. It was developed as part of our undergraduate coursework to gain practical experience in building a web-based application.

## Technologies Used

- **Backend:** PHP
- **Frontend:** HTML, CSS, JavaScript
- **Database:** MySQL

## Project Objectives

- Apply systems analysis concepts to a practical software project.
- Gain experience developing a web-based application.
- Practice working with backend technologies and database integration.
- Collaborate as a team to develop a course-related project.

## Getting Started

To run the project locally, a PHP development environment such as XAMPP may be required.

1. Clone or download this repository.
2. Set up a local PHP and MySQL environment.
3. Configure the database according to the project's configuration files.
4. Start the local server and open the application in your browser.

Refer to the project files for the specific database configuration and setup requirements.
